# MediaPipe × CNN 手認識システム

カメラに映した手の形を認識し、**グー・チョキ・パー**の3種類を分類する画像認識システムです。

MediaPipeで手のランドマークを取得し、その情報を画像として処理したものをCNNへ入力して分類します。

---

## 📌 できること

* カメラから手の映像を取得
* MediaPipeによる手のランドマーク検出
* グー・チョキ・パーの画像データ作成
* 作成したデータを使用したCNN学習
* 学習結果の保存
* 実験ごとの設定・データ・結果の保存
* 保存した過去の実験環境の復元
* 過去の実験からAccuracyが最も高い結果を自動選択
* 学習済みモデルを使用したリアルタイム認識

---

# 🚀 基本的な使い方

基本的な流れは次の通りです。

```text
データ作成
   ↓
学習
   ↓
実験結果を保存
   ↓
リアルタイム認識
```

---

## 1. 学習データを作成する

以下を実行します。

```bash
python -m src.main.data_train_make_main
```

カメラの映像が表示されます。

手の形を作り、キーを押して画像を保存します。

| キー    | ラベル |
| ----- | --- |
| `g`   | グー  |
| `c`   | チョキ |
| `p`   | パー  |
| `ESC` | 終了  |

保存された画像はCNNの学習に使用されます。

---

## 2. テストデータを作成する

テスト用データを作成する場合は、

```bash
python -m src.main.data_test_make_main
```

を実行します。

操作方法は学習データの作成と同じです。

テストデータは学習には使用せず、学習したモデルの評価に使用します。

---

## 3. 学習する

学習を実行する場合は、

```bash
python -m src.main.learning_main
```

を実行します。

学習では、学習用データを使用したTRAINと、テスト用データを使用したTESTが実行されます。

実験結果は `result` フォルダに保存されます。

例えば、

```text
result/
└─ 20261003_1507/
   ├─ log/
   │  └─ accuracy.csv
   ├─ config/
   └─ data/
```

のように、実験ごとに別のフォルダとして保存されます。

これにより、後から設定やデータを変更しても、過去の実験結果を残しておくことができます。

---

# 📊 実験結果

各実験では、Accuracyなどの結果が保存されます。

```text
result/
├─ 20261001_1200/
├─ 20261002_1500/
└─ 20261003_1507/
```

それぞれの実験には、

```text
log/
config/
data/
```

が保存されます。

### log

学習・テストの結果を保存します。

```text
log/
└─ accuracy.csv
```

### config

その実験を行った時点の設定を保存します。

そのため、後から現在の設定を変更しても、過去の実験設定は残ります。

### data

その実験で使用したデータを保存します。

これにより、実験時の環境を後から復元できます。

---

# 🔄 過去の実験を復元する

保存されたResultから、以前の実験環境を復元できます。

復元時には、

* 設定
* データ

が保存されたResultから現在の環境へ戻されます。

これにより、

```text
過去の実験
    ↓
設定・データを保存
    ↓
現在の環境を変更
    ↓
過去の実験を選択
    ↓
当時の環境を復元
```

という使い方ができます。

---

# 🏆 最高Accuracyの実験を復元する

復元時には、Resultの名前を直接指定するだけでなく、保存されている実験結果から**Accuracyが最も高いResultを自動的に選択**できます。

つまり、

```text
result/
├─ 実験A → Accuracy 0.82
├─ 実験B → Accuracy 0.91
└─ 実験C → Accuracy 0.87
             ↓
        実験Bを自動選択
```

という使い方ができます。

大量に実験を行った場合でも、結果を一つずつ確認する必要がありません。

# ⚙️ 設定

動作に関する設定は `config` フォルダにまとめられています。

## カメラ

```text
config/camera_dat.yaml
```

カメラに関する設定を行います。

## 画像処理

```text
config/frame_dat.yaml
```

画像の処理方法などを設定します。

## MediaPipe

```text
config/mediapipe_dat.yaml
```

MediaPipeによる手の検出に関する設定を行います。

## 学習

```text
config/learning.yaml
```

学習回数、バッチサイズ、シャッフルなどを設定します。

例：

```yaml
train:
  epoch: 3
  batch: 100
  shuffle: True
```

## CNN

```text
config/CNN_dat.yaml
```

CNNの入力サイズやネットワーク構成、学習方法などを設定します。

# 🎥 リアルタイム認識

学習済みモデルを使用して手の形を認識するには、

```bash
python -m src.main.interface_main
```

を実行します。

カメラに手を映すと、認識結果と信頼度が表示されます。

現在の認識対象は、

```text
Guu   → グー
Choki → チョキ
Paa   → パー
```

の3種類です。

`ESC` を押すと終了します。

# ⚠️ 注意事項

* カメラが正常に使用できる状態で実行してください。
* 学習データとテストデータは用途を分けて用意してください。
* 照明、背景、手の位置などによって認識結果が変化する場合があります。
* データや設定を変更した場合は、必要に応じて再学習してください。
* `model` フォルダに必要なモデルファイルが存在することを確認してください。
* 過去のResultを復元すると、現在の設定・データが置き換わる場合があります。
